Docs

      

        
1. Add the chat widget (easiest)

        
Paste this just before </body> on any page. Use your own key from the API Keys tab.

        

        
Optional attributes: data-title, data-color (e.g. #e11d48), data-greeting, data-position (left or right).

      

      

        
2. Chat API

        
POST /v1/chat returns { reply, images[], sources[] }. Images are base64 (mimeType + data). Keep the conversation by sending messages.

        

        
To send a picture for the AI to look at or edit, add images: [{ "mimeType": "image/jpeg", "data": "<base64>" }] to a user message.

      

      

        
3. Image API

        
POST /v1/images with { "prompt": "..." }. Returns { images: [{ mimeType, data }] }.

        

      

      

        
Good to know

        
Keys placed in a web page are visible to visitors, so set Allowed sites for each key. For server-side use, keep the key secret and rotate it if it leaks.

        
Limits per key: . Errors return { "error": "..." } with status 400, 401, 403, 429 or 5xx.
